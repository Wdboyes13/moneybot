# Security Policy

## Security standards  
- All private keys/tokens MUST not be commited or added to the repository under any circumstances or in any form
- All code must be under the MIT license, this allows us to easily check for any vulnerabilities  

## Reporting a Vulnerability

Vulnerabilities should be described in full detail, including an explanation of how it can be exploited,
how it can affect users/servers, and where in the code the vulnerability is.
